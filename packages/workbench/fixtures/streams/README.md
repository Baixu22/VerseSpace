# 无消费者的流协议参考样本

本目录是**参考样本**，不是测试夹具：全仓没有任何代码、测试或脚本读取这里。

| provider | 文件数 | 状态 |
| --- | --- | --- |
| `cursor/` | 7 | 主线尚无对应车道 |
| `kimi/` | 3 | 同上 |
| `opencode/` | 9 | 同上 |

这 19 个文件与 `src/chat/fixtures/streams/` 下的 claude（19）/ codex（11）同源，
都属于 2026-09-21 按 ADR-0015 从 `src-tauri/tests/fixtures/streams/` 整体迁入的
49 个 `.jsonl` 夹具。有消费者的 30 个留在 `src/` 里（与它们的测试同目录）；
这 19 个没有消费者，已移出 `src/` 到这里，以免在源码树里被误认为测试夹具。

**为什么保留而不是删除**：ADR-0015 决策 1 专门写了「为什么连没有消费者的 4 个 provider 也搬」
——线协议形状不能靠回忆重建，删掉 `src-tauri/` 后若不留存，这些形状就只剩 git 历史可查。
保留是当时的显式决定；要永久删除应当另立 ADR 条目记录这次反转，而不是当作静默清理。

原路径可在提交 `944b9d6` 及更早版本查阅。
