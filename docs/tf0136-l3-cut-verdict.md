# TF-0099 及其子节点废止判决书（2026-09-09）

判决书承接 `docs/tf0136-verdict.md` 的「判决四」框架与 2026-09-06 历史候选的结论。**本判决不改变 L3 的自然使用门槛**——自然使用 14 天仍是 `natural` 来源才被允许打开 L3 复评的判据；本判决说的事「L3 的所有行为证据口径在代码库里是结构性零」，这不是「再等自然使用」就能改变的事，是**无论多久这条口径都不会自明**。

## 判决四：L3 显式衍生产物

### 事实 A：结构性零事件

`variant.promoted` / `promotion_reverted` 是 L3 的可观测行为事件（只有它们能让 TF-0100 的 N=2 推导和 TF-0101 的重放验证留下数据痕迹）。

证据：
- 代码库 grep：`packages/workbench/**` 内零个生产者、零个事件类型定义。
- 事件原：`workbench-e2e-live-tenant` 4981 条事件 0 次命中；`docs/fit-ledger.md` 明确写了该判据「该事件类型从未产生」。
- 2026-09-06 历史候选已确立同一结论，本轮复核 grep 仍全零。

结论：不是「还没用到」，是「定义上就无人生产」。开不开 L3 都改变不了这个零。

### 事实 B：工程三项判决已 supported，L1 恢复卡替代了 L3 的建议能力

2026-09-08 live-tenant 账本（`docs/fit-ledger-2026-09-08-live-tenant.md`）：
- 判决一恢复卡 supported（消费比 0.43、动作数 23）。
- 判决二前提检测 supported（delivered=29、dismissed/ignored/unknown 全 0）。
- 判决三阶段 C supported（forks=24、继承观测=3）。
- 护城河 A/B/C/D 四门齐开。

L3 的「自动建议下一个操作」被这三项判决覆盖：**前提检测告诉写者该看什么、阶段 C 给结构化的回读路径、恢复卡把断点工作版化**。用户不再需要从相近轨迹之间推导泛化。

### 事实 C：外部研究证据（引用自 TF-0099 节点）

ALLOY (UIST'25)：推导出的结构正确性输给手写（9/12 vs 10/12）；规格挖掘误报 90–99%；LLM 解冲突与开发者一致率 55–59%。

### 事实 D：L3 内的两类成分都不存在的保护法

- TF-0100 「N=2 推导」承认、没有 promo 事件比对的两条轨迹不能留下数据痕迹。
- TF-0101 「重放验证 + 逐字面量占位符」给 promo/revert 参数本身设定出校门，但它在业主 ~0 称。

### 结论

**TF-0099 → deprecated；TF-0100 → deprecated；TF-0101 → deprecated（图独立，不在树下）。**

TF-0136 判决四定格为「L3 已砍」，不再出现在 insufficient-evidence 循环里。复评条件（永不成的 natural 14d）因此不再是一个可等待的条件——因为 A 明确说自然使用如何都无法改变事实 A。

TF-0108 「风险：L3 明确超前于证据」→ 该风险已被规避行为消灭，节点转 deprecated（风险已收敛）。
