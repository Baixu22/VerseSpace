# ADR-0024：永久关闭非 Windows 实机验证与真人研究

- 状态：已接受（2026-09-28，维护者明确要求永久关闭，并确认保留交叉编译产物）
- 取代 ADR-0019、ADR-0023 中将这两项保留为常设外部门或独立后续工作的安排；不改变既有证据。
- 关联森林节点：TF-0237、TF-0251、TF-0265、TF-0267；发行仍由 TF-0266 追踪。

## 决定

1. 永久关闭 Linux/macOS 实机测试与冒烟验证，不再等待 WSL、重启、远端主机或 CI，不再把它们列为收尾条件。继续保留 windows-x64、linux-x64、macos-arm64、macos-x64 四平台交叉编译及发行资产。
2. 永久关闭真人自然使用窗口与生产率研究，不再征集真人、提醒补样本或由 agent 代跑。既有指南与原始判据作为历史保留。
3. 关闭属于范围决定，不是实验通过；相关节点保持 deprecated，禁止改记 done 或生成通过读数。跨平台执行、自然使用效果与生产率收益仍未验证。
4. Windows 工程验证、真实浏览器自动化和可用条件下的 Codex 实验继续保留。浏览器自动化不是本决定关闭的真人研究。Codex 仍是实验通道，单测通过或实验 exit 0 均不能直接证明写保护。
5. 发行仍需版本、CHANGELOG、受测提交、tag 与资产 SHA256 对齐；发行说明持续披露非 Windows 产物仅交叉编译。

## 执行与历史

README、包说明和发布说明采用上述范围。旧 ADR、交接记录及操作指南中的后续建议仅代表当时状态，由本决定取代，不重写旧读数。此决定不修改用户机器的 WSL、系统虚拟化或全局配置。
