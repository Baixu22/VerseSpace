# ADR-0008：结构从执行推导，不从对话推断；交互层只做加法

- 状态：提案（待用户裁决）
- 日期：2026-08-30
- 相关：[`positioning-v6.md`](../positioning-v6.md)（交互层）· [`positioning-v5.md`](../positioning-v5.md) §11.3 R1′（共用同一份采集）

## 背景

交互层需要回答一个问题：**结构（任务、计划、可复用流程、工作区）从哪里来？** 三个候选：

1. **用户前置声明**（Coze / Dify 式工作流 DAG）
2. **系统从对话文本推断**（渐进形式化、结构识别器、画布 + 空间解析）
3. **系统从执行轨迹推导**（工具调用、文件读写、测试结果、提交）

### 候选 1 已被文献判决

Shipman & Marshall《Formality Considered Harmful》（CSCW 8:333–352, 1999）列出用户拒绝结构的四个原因——认知开销、默会知识、过早结构、**情境结构**——并直接指出：

> "无法处理形式化流程之例外的系统，无法支持那大量需要例外流程的情形……**几乎所有办公流程最后都是规定形式的例外**（Suchman 87）。"

补充经验约束：中位任务只有 2–4 轮（LMSYS-Chat-1M 平均 2.0 轮；WildChat 约 59% 单轮；Anthropic Clio 40 万会话中典型 Claude Code 会话约 4 轮）。**任何带每会话前置成本的结构，摊销分母≈0。** 且用户不会成长到高级用法（微软《Adopt ≠ Adapt》，约 12,000 用户 6 个月纵向，"基本否定"个体会学成高级用户）。

### 候选 2 是一片有 35 年记录的墓地

同一篇文献同时警告：

> "我们希望揭穿一条**危险地诱人的推理**：只要你为嵌入式表示造出对的界面，用户就会去形式化。"

反证由该阵营自己发表：VKB "人们很少回头把信息空间弄一致"，纵向 N=2 的学生"推迟结构化直到理解更多"**然后再没有过**，作者自陈短期研究中的视觉规律性可能是**会磨掉的新奇效应**；Aquanet 两年后形式化"缓慢、冗余、不一致"；IBIS 的成功"依赖严厉的社会压力、大量培训或持续人工引导"。现代记录：**Tinderbox 主动移除识别器**；Obsidian Canvas 规格层面惰性；**Ink & Switch 三次尝试后原话"我们总体上怀疑这件事能否做到可靠"**；Muse、Kosmik 相继关停，而最健康的 Heptabase 承诺的自动化最少。

从散文推断的量化上限也很低：规格挖掘 **90–99% 误报率**（调平衡时 63% 精度），**无一交付给开发者**。

### 候选 3 的可验证性来自符号 API

追溯式结构化的成功条件里最锐利的一条：**"轨迹建立在稳定的符号 API 上就能泛化；建立在渲染出来的界面上就不能"**（Photoshop 动作存活 vs Selenium 录制崩溃：453 个版本 1,065 次损坏中 **>73% 由定位器造成**）。

**工具调用就是稳定的符号 API。** 而 Coze/Dify 必须问用户要结构，**因为它们编排 API 调用而没有地面真相**。本项目有 git：哪些文件被碰、哪些测试跑了、什么被提交了——**这是真实发生的结构，不是被推断的意图。**

## 决策

### 1. 采纳候选 3，明确拒绝 1 与 2

> **对话是输入面。执行是结构的来源。仓库是结构的裁判。用户永远不画图。**

### 2. 线性对话不动

零改动。所有结构发生在它**之上**或**之下**，从不发生在**它里面**。

### 3. 交互层只做加法，绝不破坏

三项对照研究一致：**破坏性自适应输给静态**（Findlater & McGrenere n=27，三种顺序 p=.002/<.001/<.001），且被 **15/27** 评为最令人沮丧（对照"可自定义"仅 1/27）；**纯加法式自适应在 79% 准确率时快于静态，50% 时也不显著变慢**（n=48）。

> **准确率是错的轴，破坏性才是。**

因此：被提议的任务/工作区必须是**盖在现有对话之上的一层**——同一段滚动历史、同一个位置、**什么都不移动、什么都不改名**。若接受提议会重排或重新格式化对话，即为已知会输的那个设计。

### 4. 两层隔离：隐式层容忍噪声，显式层不容忍

- **隐式层（L1）**：Mylyn 式 DOI。**永远采集、永不呈现为"待批准的产物"、容忍约 30% 噪声、只用于加权重与排序。** 依据：Mylyn 是本领域唯一带 p 值的生产率胜利（编辑比配对 t 检验 **p=0.003**，16 人中 13 人改善），而其上下文含约 **28% 假编辑事件**——**一个 28% 错误的产物带来了可测量的提升，因为没有任何东西依赖它正确，也没有人需要批准它。**
- **显式层（L3）**：必须满足四条——**N=2 才推导**（两条相似轨迹之差即泛化）、**用重放而非阅读验证**、**泛化逐字面量可见可拒绝**、**保留轨迹且产物只是有损索引**。

### 5. 杀死判据

> **若一个衍生产物无法通过执行来检查，且其输出空间是开放的（一个计划、一份规格、一篇设计文档）——不要建它。**

依据：规格挖掘 90–99% 误报区；而 METR 的 RCT 显示开发者**慢了 19% 却以为快了 20%**——**验证成本对付钱的人不可见，用户不会告诉你它在失败。**

### 6. 提议的阈值先算再建

```
p <  K/B          → 沉默
K/B ≤ p ≤ 1−K/C   → 提议
p >  1−K/C        → 直接做
```

**当 `K(1/B + 1/C) > 1` 时提议区间为空**——不存在任何 p 使询问最优。**"要不要把它变成一个任务？"这类提示大多数不通过此检验；不通过就删掉提示，选一边站。**

### 7. 模式必须可见且对称

实测：**用户自己保持的模式状态防止模式错误的效果比最显著的视觉反馈还好约 3 倍**（ω² 15.6% vs 4.8%），**而系统保持的"锁定式"模式在统计上与完全没有指示器无法区分**（p<.33）。**自动晋升是实测中最糟的那一档。** 缓解只有：常驻、不可错过、退出与进入代价对称。

### 8. 明确不做

画布/空间界面（零篇留存率胜利；无识别器的画布是垃圾累积器）· 结构识别器 · 让用户命名或分类分叉（Giornata：全部被试整个研究期间仅改过 12 次标签，14.8% 永久无标签）· 每周回顾式摘要（GTD 每周回顾**零实证支持**）· 自动任务边界检测（Bardram 试过 RFID："太粗、太不精确"，退回人工信号）· 用户编排的 DAG 编辑器（PromptChainer 退化到 4 个案例用户——**结构成本只是被推走，没有消失**）· 生成式 UI（76 用户 380 查询：50.8% 胜 / 41.1% 负，掷硬币）。

## 后果

**正面**

- 与 v5 共用同一份采集：`used` / `generated` / 工具调用序列 / Verifier 结果 **一次采集，两处使用**；R1′ 同时是 v6 的前置条件，不新增管线。
- 结构来源可验证（重放），避开了 90–99% 误报的区域。
- 与"产品必须可证明地不是编排器"一致——**用户永远不画图**是它在交互层的对应表述。
- 隐式层单独就有 p 值背书，即使 L2/L3 全部砍掉也仍有价值。

**负面 / 风险**

- **L3 明确超前于证据。** 从对话追溯结构几乎没有实证文献；Graphologue、Sensecape 均为小样本实验室原型，无纵向与信任度数据。**这是风险最高的一层，应最后建、最容易砍。**
- **隐式层的常数必须按生命周期变。** Mylyn 只有一套全局常数且数据显示**同时在两个方向失败**（2.06% 的选择落在已衰减出视野的元素上；两位被试点了 225 和 210 次"降低兴趣"），作者指出模型"对任务的生命周期是盲的"却从未修。这是必须补上的洞。
- **不要重蹈 Mylyn 的第二个覆辙**：其"聪明的那一半"（预测式检索）**只有五个用户重复使用过**；活下来的是无聊的那一半（捕获、过滤、恢复）。
- **廉价撤销的系数从未被测量。** "C→0 则永远直接做"这个方向 Horvitz 陈述过，但 HCI 与 AI 安全都没有测过系数。同时 Gilbert & Ebert 实测：**人偏好可逆决定（66.3%）但对其结果满意度更低**（p=.03）——**廉价撤销用承诺感换接受度**。故：让**提议**极易撤销，让**工作区一旦进入就感觉是定下来的**。
- **Horvitz 的十二原则与 `p*` 推导是框架，未被测量**；LookOut 本身没有任何对照的准确率/收益评估，**不能引为"混合主动有效"的证据**。
