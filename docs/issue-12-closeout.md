# Issue #12：产品评估重启条件

2026-09-16。此项交付是可核验的重启清单，不是现在启动产品评估，也不把工程测试改写成自然使用证据。

三项条件必须同时满足：

| 条件 | 重启时必须能核验的证据 | 当前处置 |
| --- | --- | --- |
| human 读集有自动生产路径 | 实际编辑器或其他用户操作面的生产入口、触发说明，以及由该入口自动产生的 writer/used 记录；手动 CLI、脚本或模型伪装 human 不算 | 尚无符合条件的生产入口；以后实现时单独立项并验证来源归属 |
| 有真实使用者参与封印复核 | 实际使用者对其工作中封印结果的逐项结论，能关联原始会话和封印事件；保留未答条目及复核覆盖率 | 等待实际使用者；不复用模型的意见，也不由维护脚本代答 |
| 有真实使用窗口的读数 | 声明自然使用来源及起止时间，能回查原始 footprint、premise_pass 和通知事件，并按既定 10–30% 比值带复核 D | 等待自然使用记录；soak 或安排好的模型场景仅作工程证据 |

重启时**新开节点，不复活 TF-0167**。新节点须引用以上三组证据，保持原阈值，并单独规划 L1 的真实使用者评估。
