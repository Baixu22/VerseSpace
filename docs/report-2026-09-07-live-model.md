## 后续直接运行

Windows 当前用户的密钥已通过 DPAPI 加密保存在仓库外，运行器只在子进程环境中使用它，结束后恢复原环境。无需把密钥写进 Workbench YAML。

```powershell
# 在 packages/workbench 目录；从空白隔离工作区建立会话并完成真实运行
powershell -NoProfile -File scripts/e2e/run-live.ps1

# 只检查加密凭据可读取，不发送模型请求
powershell -NoProfile -File scripts/e2e/run-live.ps1 -CheckOnly
```

其他环境可设置 `E2E_LLM_KEY`、`E2E_LLM_MODEL`、可选 `E2E_LLM_BASE_URL` 后运行 `bun run test:live`。普通 `bun test` 不访问远端模型。
